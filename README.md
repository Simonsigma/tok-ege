# TOK — ЕГЭ LAB

Готовый мобильный сайт для подготовки к ЕГЭ по химии и биологии.

## Как запустить
1. Создай на GitHub новый публичный репозиторий, например `tok-ege`.
2. Нажми **Add file → Upload files**.
3. Загрузи `index.html` из этой папки и нажми **Commit changes**.
4. Открой **Settings → Pages**.
5. В разделе **Build and deployment** выбери `Deploy from a branch`, ветку `main`, папку `/ (root)` и нажми Save.
6. Через минуту сайт появится по адресу `https://ТВОЙ-ЛОГИН.github.io/tok-ege/`.

## Что уже работает
- Лента учебных карточек по химии и биологии.
- Три тематические реакции на каждый пост.
- Комментарии.
- Поиск по темам.
- Мини-тест с проверкой ответов и объяснениями.
- Профиль, очки TOK и сохранение прогресса в браузере.

## Важно
Это первая самостоятельная версия без сервера и регистрации. Данные хранятся локально в браузере пользователя. Чтобы добавить общую ленту, аккаунты и синхронизацию между устройствами, позже понадобится база данных и серверная часть.
